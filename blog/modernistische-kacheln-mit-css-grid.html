Modernistische Kacheln mit CSS Grid

Sechs Motive, ein Raster, ein einziger Kachel-Baustein — wie aus vier gedrehten Formen ein ganzer Boden aus Mustern entsteht, komplett in CSS.

P Philipp Senior Lead Developer & Head of E-Commerce Shop

Modernistische Kachelböden sind in Barcelona Alltag: sechs Motive, hundert Jahre alt, und trotzdem in jedem Treppenhaus anders. Genau dieses System lässt sich mit CSS Grid nachbauen — vier Formen, ein paar Rotationen, fertig ist der Boden.

Der Reiz liegt nicht in der einzelnen Kachel, sondern im Übergang. Jede Fliese endet an einer Kante, an der die nächste weiterlaufen muss — und weil die Motive symmetrisch sind, entstehen über vier Kacheln hinweg Formen, die auf keiner einzelnen Fliese existieren. Das ist der ganze Trick, und es ist ein Trick, den ein Raster gratis mitbringt.

Ich habe mit der Palette angefangen, nicht mit dem Code: drei Grundtöne, ein Akzent, ein Papierweiß als Fugenfarbe. Alles Weitere sind Varianten davon.

01Die Anatomie einer Kachel

Eine Kachel ist ein 2×2-Raster aus vier identischen Zellen. Jede Zelle bekommt dieselbe Form, nur um 90 Grad weitergedreht. Vier Zellen, vier Rotationen — das ist das ganze Markup.

.tile {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  aspect-ratio: 1;
  gap: 0;
}

.tile__cell:nth-child(2) {
  rotate: 90deg;
}
.tile__cell:nth-child(3) {
  rotate: 270deg;
}
.tile__cell:nth-child(4) {
  rotate: 180deg;
}

Das Motiv selbst steckt ausschließlich im Hintergrund der Zelle. Fan ist ein einzelner Radial-Gradient, an eine Ecke gepinnt und hart abgeschnitten — ein Viertelkreis ohne SVG, ohne Maske.

.cell--fan {
  background: radial-gradient(circle at 0% 0%, var(--tile-accent) 62%, transparent 62%);
}

Alle sechs Motive teilen dieselbe Zelle. Lens rundet zwei gegenüberliegende Ecken und macht aus dem Quadrat ein spitzes Oval, Wedge schrumpft die Form und pinnt sie in die Mitte, Star schneidet sie in vier Dreiecke. Kein Motiv braucht neue Geometrie — nur andere Werte.

02Rotation statt neuer Formen

Der Grund, warum sechs Motive mit einem Baustein auskommen: Rotation ist in CSS eine Eigenschaft, keine Form. Wer rotate pro Zelle setzt, bekommt Spiegelachsen gratis — und mit ihnen die Diagonalen, die über Kachelgrenzen hinweg weiterlaufen.

Ein Muster ist nie die Kachel. Es ist das, was zwischen vier Kacheln passiert.

Deshalb muss die Form symmetrisch sein. Sobald ein Motiv eine bevorzugte Richtung hat, bricht die Naht: Man sieht, wo eine Fliese endet. Symmetrie ist hier keine Stilfrage, sondern Bedingung.

03Warum die Naht die Arbeit macht

Im Raster treffen an jeder Ecke vier Kacheln aufeinander. Die Motive laufen weiter, weil ihre Kanten identisch enden — und wo sie das nicht tun, entsteht sofort ein Gitter aus sichtbaren Fugen. Im Zweifel hilft der brutalste Test: Kachel duplizieren, um 180 Grad drehen, danebenlegen. Wenn man die Grenze findet, ist das Motiv noch nicht fertig.

.floor {
  display: grid;
  grid-template-columns: repeat(8, 1fr);
  --tile-color: #7f2b3a;
  --tile-accent: #efe6d2;
}

/* kein Motiv-Wechsel nötig: nur Variablen */
.floor--ocean {
  --tile-color: #24506b;
  --tile-accent: #e8eef2;
}
⚠ Warnung

Subpixel-Fugen sind der häufigste Fehler: Sie entstehen, wenn Zellen auf gebrochene Pixel fallen — ein outline: 1px solid var(--tile-accent) auf der Zelle deckt sie zuverlässig ab, ohne das Layout zu verschieben.

04Was davon bleibt

Das Projekt hat drei Tage gedauert und mir mehr über CSS-Gradients beigebracht als jedes Tutorial: Ein Gradient ist eine Form, wenn man ihn hart abschneidet. Ein Raster ist ein Muster, wenn die Kanten stimmen. Und eine Palette ist wichtiger als jede Technik.

Die Demo oben gibt es auch als eigenständige App: Tile Lab. Es ist dieselbe Komponente — sie liegt im Design System, nicht in diesem Artikel, und genau deshalb kann sie an beiden Orten stehen, ohne zweimal zu existieren.
